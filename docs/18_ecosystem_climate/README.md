# 18 — Ecosistema, ambiente y cambio climático

> [Volver a `docs/`](../) · [Incertidumbres](../14_uncertainty_scenarios/) · [Mapa completo](../../REPOSITORY_MAP.md)

Esta etapa evalúa si procesos ambientales o ecosistémicos pueden cambiar las conclusiones de manejo. No todos los MSE necesitan un modelo ecosistémico completo; deben incorporarse los mecanismos que sean **materiales para la decisión**.

## Procesos posibles

- demanda de presas por depredadores y función de pez forraje;
- competencia con otras especies;
- cambios de productividad del sistema;
- eventos ambientales extremos y regímenes climáticos;
- calentamiento y cambios persistentes de hábitat;
- desplazamientos de distribución espacial;
- relaciones entre ambiente y reclutamiento, crecimiento, mortalidad o disponibilidad.

## Cuidado con las relaciones ambientales

Una relación histórica entre una variable ambiental y el reclutamiento puede debilitarse, cambiar de signo o desaparecer en el futuro. Si una MP utiliza directamente una relación ambiental, el Robustness Set debería incluir escenarios donde esa relación sea más débil o se rompa.

El ambiente debe incorporarse mediante mecanismos ecológicamente defendibles. Agregar muchas covariables sin una hipótesis causal clara puede aumentar complejidad sin mejorar la decisión de manejo.
