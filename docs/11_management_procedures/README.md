# 11 — Procedimientos de manejo y reglas de decisión

> [Volver a `docs/`](../) · [Especificación mínima](../../models/management_procedures/) · [Configuración](../../config/management_procedures/) · [Mapa completo](../../REPOSITORY_MAP.md)

Un **procedimiento de manejo (MP)** es el conjunto preacordado de información, cálculos y reglas que produce una acción de manejo. Una HCR puede ser una parte central de la MP, pero normalmente no describe todo el procedimiento.

## Cada MP debe responder claramente

1. ¿Qué datos recibe?
2. ¿Se utiliza una evaluación de stock, un estimador o un indicador directo?
3. ¿Cuál es la regla de decisión?
4. ¿Qué acción produce: cuota, esfuerzo, cierre, límite espacial, medida sobre juveniles u otra?
5. ¿Cuándo se aplica y con qué frecuencia?
6. ¿Existen límites máximos/mínimos o restricciones de cambio entre periodos?
7. ¿Cómo se redondean o traducen las recomendaciones a medidas operativas?
8. ¿Qué ocurre si faltan datos o falla la evaluación?

## Primero reconstruir el statu quo

Antes de proponer reglas alternativas, documente el procedimiento de manejo realmente utilizado por la pesquería. Esto permite comparar nuevas MPs con un punto de referencia institucional realista y detectar qué componentes del manejo actual son discrecionales, adaptativos o difíciles de formalizar.

## Diseño y ajuste son etapas diferentes

El **diseño** define la estructura de la MP. El **tuning** ajusta valores de sus parámetros para cumplir objetivos previamente acordados. No cambie la estructura o los objetivos de forma oportunista después de observar qué alternativa obtiene mejores resultados.
