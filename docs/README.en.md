# Scientific and institutional documentation (`docs/`)

> **Primary documentation language:** Spanish · [Versión en español](README.md) · [Repository map](../REPOSITORY_MAP.en.md)

This folder explains **what is being modeled, why scientific choices were made, and how the real management system works**. The numbered subfolders follow the MSE cycle from onboarding, management objectives, stock ecology, fishery, management, monitoring and assessment through OM/observation/estimation/implementation, Management Procedures, performance metrics, uncertainty, experimental design, validation, tuning, ecosystem/climate, economics, exceptional circumstances, post-adoption monitoring, reporting, and quality assurance.

The Spanish README provides a linked table with the question answered by each numbered folder. A material code or configuration change should have its scientific rationale documented in the corresponding `docs/` section.
