# Reproducible reports (`reports/`)

> **Primary documentation language:** Spanish · [Versión en español](README.md) · [Repository map](../REPOSITORY_MAP.en.md)

This folder contains the source files for reproducible MSE reports. `technical/` is for the full scientific report, `management/` for decision-oriented summaries, and `stakeholder/` for workshop and communication material.

Tables and figures should be generated from identified simulation runs rather than copied manually. Formal advice should be traceable to `registry/run_registry.csv` and, when appropriate, to certified run manifests.
