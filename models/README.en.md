# Scientific component specifications (`models/`)

> **Primary documentation language:** Spanish · [Versión en español](README.md) · [Repository map](../REPOSITORY_MAP.en.md)

This folder contains plain, declarative **minimum scientific requirements** for each component of the closed-loop MSE. The YAML files describe what an implementation must be able to represent; they are not the executable models themselves.

Subfolders cover the Operating Model, observation model, estimation/assessment, implementation model, Management Procedures, and reference points. The corresponding scientific rationale belongs in `docs/`, while concrete run settings belong in `config/`.
