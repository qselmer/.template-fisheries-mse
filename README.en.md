# Management Strategy Evaluation (MSE) for fisheries

<br clear="right">

> **Primary documentation language:** Spanish. [Versión en español](README.md) - [Repository map](REPOSITORY_MAP.en.md)

This repository is a reusable template for a complete Management Strategy Evaluation of a fishery, species, or stock. It is intentionally generic and does not contain real-species parameters.

The main documentation is written in Spanish. Start with [`README.md`](README.md), then use [`REPOSITORY_MAP.md`](REPOSITORY_MAP.md) to navigate to the relevant scientific or computational component.

The template covers management objectives, evidence and data, Operating Models, observation and estimation, Management Procedures, implementation, performance metrics, uncertainty, simulation design, monitoring, exceptional circumstances, reporting, and certification.

**Template version: 1.0.3 - 2026-09-02.**
