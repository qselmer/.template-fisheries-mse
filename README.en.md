# Fisheries MSE<br>Template

Reusable template for reproducible fisheries **Management Strategy Evaluation (MSE)** projects.

<br clear="right">

> **Primary documentation language:** Spanish. [Versión en español](README.md) · [Repository map](REPOSITORY_MAP.en.md)

This repository is a public **`type-template`**. It provides a reusable structure for a complete MSE of a fishery, species, or stock and intentionally contains no real-species parameters.

A repository created with **Use this template** should normally become a **`type-project`**, because an applied MSE is typically a scientific project that can produce multiple outputs. The inherited `repo.yml` must therefore be updated immediately with the new repository identity, status, stage, visibility, topics, and integrations.

The template covers management objectives, evidence and data, Operating Models, observation and estimation, Management Procedures, implementation, performance metrics, uncertainty, simulation design, monitoring, exceptional circumstances, reporting, and certification.

GitHub Actions validate the template infrastructure, YAML metadata, and Python syntax. They do not certify the scientific validity of an applied MSE.

Start with [`README.md`](README.md), then use [`TEMPLATE_USAGE.md`](TEMPLATE_USAGE.md) and [`REPOSITORY_MAP.md`](REPOSITORY_MAP.md) to navigate the scientific and computational structure.

**Template version:** `1.0.0`  
**Repository type:** `type-template`  
**Default generated type:** `type-project`
