# Configuration files (`config/`)

> **Primary documentation language:** Spanish · [Versión en español](README.md) · [Repository map](../REPOSITORY_MAP.en.md)

Configuration files are machine-readable parameter sheets. They tell the code **which model options, scenario, Management Procedure, or experiment to run**. They should implement decisions that are already justified in `docs/` and traceable in `registry/`; they are not a substitute for scientific documentation.

The main files configure the Operating Model, observation model, estimation/assessment, implementation model, and performance metrics. Subfolders define the Reference Set, Robustness Set, candidate Management Procedures, experiment design, and publication-related settings.
