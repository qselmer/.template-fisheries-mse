# Historial de cambios

## 1.0.3 - 2026-09-02
- El template se generalizó para cualquier especie, stock o pesquería.
- Se eliminó la referencia a especies pelágicas del título, perfil de ejemplo, metadatos y documentación principal.
- `species_profile.yml` ahora utiliza campos genéricos (`Example species`, `Example stock`, `Example management area`) y valores `TBD`.
- El logo se renombró a `assets/logo_hex_mse.svg` y se mantuvo como identidad visual general del repositorio.
- La portada del `README.md` se reorganizó con el título a la izquierda y el logo a la derecha.
- Se generalizaron las secciones de biología/ecología, incertidumbre y uso del template.

## 1.0.2 - 2026-09-02
- Se agregó un logo hexagonal minimalista para identificar el template.
- Se refinó la descripción inicial para ecólogos, biólogos pesqueros, evaluadores de stock y consultores.
- Se explicó de forma directa la función de los archivos visibles en la raíz del repositorio.
- Se mejoró la descripción de las carpetas principales sin modificar la arquitectura científica.
- En la documentación principal se sustituyeron rayas largas por guiones simples.

## 1.0.1 - 2026-09-02
- Reescritura del `README.md` para ecólogos, evaluadores de stock y científicos pesqueros, con menos jerga de programación.
- Nuevo `REPOSITORY_MAP.md` con árbol navegable, enlaces directos y explicación de cada carpeta y subcarpeta.
- Nuevo `GLOSSARY.md` con términos de MSE y términos computacionales explicados en lenguaje directo.
- Nuevo `TEMPLATE_USAGE.md` para iniciar un proyecto real desde la plantilla.
- Explicación clara de la diferencia entre `docs/`, `config/`, `src/`, `scripts/`, `registry/`, `outputs/` y `certification/`.
- Sustitución del término `entrypoint` por "script de ejecución" en la documentación principal y scripts de ejemplo.
- Mejora gramatical y de navegación de los README principales y de las etapas de ejecución.

## 1.0.0 - 2026-09-02
- Reconstrucción completa del template para una Evaluación de Estrategias de Manejo.
- Ciclo completo desde objetivos y diseño del MSE hasta adopción, monitoreo, circunstancias excepcionales y revisión.
- README principal en español y documentación bilingüe de carpetas.
