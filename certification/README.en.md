# Frozen, auditable versions (`certification/`)

> **Primary documentation language:** Spanish · [Versión en español](README.md) · [Repository map](../REPOSITORY_MAP.en.md)

This folder is used when an MSE version supports formal comparison, independent review, or management advice. It freezes the exact Reference Set, Robustness Set, Management Procedure version, random seeds, software versions, run manifests, and review material needed to reproduce that analysis later.

Here, “certification” means a documented frozen project version; it does not automatically imply legal or regulatory certification. Certified files should not be edited in place—create a new version instead.
