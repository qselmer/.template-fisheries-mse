# Project Charter

Template institucional para desarrollar una MSE completa de una pesquería, especie o stock, desde la definición de objetivos y evidencia hasta la adopción, el monitoreo y la revisión. Principios: trazabilidad, separación entre modelo operativo, observación, estimación, procedimiento de manejo e implementación, distinción entre Reference y Robustness Sets, riesgo explícito, reproducibilidad, protección de datos y revisión independiente.
