# Generated results (`outputs/`)

> **Primary documentation language:** Spanish · [Versión en español](README.md) · [Repository map](../REPOSITORY_MAP.en.md)

This folder contains generated simulation results. These are not primary evidence: important results should be reproducible from data, code, configuration files, and recorded random seeds.

`runs/` stores outputs by run identifier, while `figures/` and `tables/` contain derived products. Important runs should be recorded in `registry/run_registry.csv`, and formal advice should use certified manifests when appropriate.
