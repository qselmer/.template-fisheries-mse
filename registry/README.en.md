# Traceability tables (`registry/`)

> **Primary documentation language:** Spanish · [Versión en español](README.md) · [Repository map](../REPOSITORY_MAP.en.md)

Think of `registry/` as the project's scientific logbook. Its CSV tables record where sources, datasets, parameters, objectives, uncertainties, scenarios, Management Procedures, runs, decisions, exceptional-circumstance rules, and software versions came from.

The purpose is traceability: an important number or conclusion should be traceable from a result to a run, configuration, parameter or decision, and ultimately to documented evidence or an explicit scientific decision.
