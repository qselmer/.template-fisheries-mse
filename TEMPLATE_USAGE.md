# Cómo usar este template para crear un MSE real

Este repositorio es una plantilla. Al utilizar **Use this template** en GitHub, el nuevo repositorio debe representar una especie, stock o pesquería concreta.

## Cambios mínimos al crear un proyecto

1. Reemplace los campos de ejemplo en `species_profile.yml` por la información real del caso.
2. Revise `publication.yml` y la política institucional de datos.
3. Defina objetivos y tolerancias de riesgo antes de diseñar reglas de manejo.
4. Registre las fuentes disponibles en `registry/source_registry.csv` y los datos en `registry/data_inventory.csv`.
5. Documente el sistema real de manejo antes de reconstruir la MP de statu quo.
6. Mantenga como `TBD` cualquier elemento que todavía no tenga evidencia o una decisión científica formal.

## Qué no debe copiarse ciegamente

El template **no prescribe** una escala temporal, estructura espacial, modelo de reclutamiento, mortalidad natural, crecimiento, relación ambiente-reclutamiento, modelo de evaluación, puntos de referencia ni HCR. Todos esos elementos deben definirse según el caso real.

Consulte el [`README.md`](README.md) para la lógica general y [`REPOSITORY_MAP.md`](REPOSITORY_MAP.md) para navegar por las carpetas.
